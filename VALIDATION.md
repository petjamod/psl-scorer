| Model | Train Pearson | Test Pearson | Test MAE | Test RMSE | Train minus test Pearson |

| finetuned + flip average (**shipped**) | | 0.9210 | 0.1995 | 0.2649 | |

Flip average = mean of the prediction for the crop and for its mirror image, baked into the ONNX graph. Without it, mirroring a photo changes the fine tuned model's score by 0.074 on average.

The fine tuned model was trained on the train split only, so its test number is a clean held out measurement. The pretrained model shows almost no train/test gap, which suggests these weights were not trained on exactly this train split (see DECISIONS.md, decision 8), so its test number may be optimistic.

### 4. Quality gates

| Fixture | Expected | Got | Pass |
|---|---|---|---|
| neutral | no flags | no flags | yes |

| dark | lighting | Blurry or low resolution; Too dark | yes |
| noface | noface | noface | yes |
| exif_rot6 | no flags | no flags (raw diff vs upright copy 0.0022) | yes |
| big | no flags | no flags (raw diff vs Python 0.0003, vs the original 350 px image 0.0207) | yes |

`rotated30`: a SCUT face rotated 30 degrees in plane. `turned`: the SCUT test face with the largest yaw. `smiling`: the SCUT test face with the highest smile score. `two_faces`: two SCUT faces side by side. `exif_rot6`: pixels stored sideways with EXIF orientation 6, must score like the upright copy. `big`: the neutral face upscaled 4x inside a 3000x2200 frame (exercises the antialiased pre-shrink); must match the Python reference within 0.01.
